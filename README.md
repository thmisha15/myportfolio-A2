# Thmisha Rasanathan — Express Portfolio (INFR3120 Assignment 2)

Four-page portfolio built with Node.js, Express.js and EJS, using an Express Generator-style structure. This is a **new EJS project**, not HTML pages served as views.

## Setup

1. Install Node.js 20 or later.
2. In this folder, run `npm install`.
3. Run `npm start`.
4. Open http://localhost:3000 and test `/`, `/about`, `/projects`, `/contact`.

## Express Generator requirement

The assignment specifically requires use of **Express Generator**. This package contains the conventional generated layout (`app.js`, `bin/www`, `routes`, `views`, `public`) but was assembled in this environment rather than generated by the CLI. **To meet the procedural requirement, run the actual generator locally and migrate these files into its output:**

```bash
npx express-generator --views=ejs thmisha-assignment-2
cd thmisha-assignment-2
```

Then copy this package's `app.js`, `bin/www`, `routes/`, `views/`, `public/`, `package.json`, `render.yaml`, `.gitignore` and README into that folder, run `npm install`, and test. Preserve the generator-created structure. Explain this process accurately in your demonstration video.

## Routes and views

- `/` → `views/index.ejs`
- `/about` → `views/about.ejs`
- `/projects` → `views/projects.ejs`
- `/contact` → `views/contact.ejs`
- `views/partials/header.ejs` and `footer.ejs` are shared via EJS `include()`.
- `app.js` sets the EJS view engine, static assets and router.
- `bin/www` starts the HTTP server using the cloud-provided `PORT`.
